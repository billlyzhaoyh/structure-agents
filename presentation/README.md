# Presentation

`decision-os-pitch.html` is a self-contained three-slide deck for voice-over: the title
slide, the problem and why-now cards, and the database-to-experiment walkthrough.

Open the file directly in a browser. Use the arrow keys, space, or the header buttons to
move between slides. It loads Inter and Caveat from Google Fonts and needs no build step,
server, or dependency.

Every figure on the slides is illustrative demo content, not a measured model result.
